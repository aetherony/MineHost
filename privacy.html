Política de Privacidade

Esta página apresenta informações sobre como o MineHost pretende tratar os dados dos usuários quando os recursos reais da plataforma forem implementados.

1. Informações coletadas

No momento, esta versão demonstrativa não possui um sistema de cadastro ou banco de dados conectado. Futuramente, poderão ser solicitadas informações necessárias para o funcionamento das contas.

2. Uso das informações

Quando os recursos reais estiverem disponíveis, as informações poderão ser utilizadas para administrar contas e oferecer os serviços da plataforma.

3. Proteção dos dados

O projeto deverá implementar medidas adequadas para proteger as informações pessoais dos usuários.

4. Compartilhamento

Qualquer compartilhamento de dados deverá seguir a legislação aplicável e ser explicado de maneira transparente aos usuários.

5. Cookies e armazenamento

Algumas funcionalidades demonstrativas podem utilizar armazenamento local do navegador. Isso não representa um sistema completo de armazenamento de contas.

6. Direitos dos usuários

Quando houver coleta de dados pessoais, os usuários deverão ter acesso às informações sobre seus direitos, incluindo os previstos na Lei Geral de Proteção de Dados (LGPD).

7. Alterações

Esta política poderá ser atualizada conforme o MineHost evoluir e novos recursos forem adicionados.

8. Contato

Os canais oficiais de contato serão divulgados quando o sistema de atendimento estiver implementado.
