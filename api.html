MineHost API

Documentação da API

Bem-vindo à documentação da API MineHost. Aqui você encontrará exemplos de como os sistemas poderão se comunicar com a plataforma.

Endpoints planejados

GET /api/status

Consultar o status geral da plataforma.

GET /api/servers

Consultar a lista de servidores da conta.

POST /api/servers

Solicitar a criação de um servidor Minecraft.

GET /api/servers/{id}

Consultar informações de um servidor específico.

POST /api/servers/{id}/start

Solicitar a inicialização de um servidor.

Autenticação

Futuramente, a API utilizará autenticação segura para proteger as informações das contas.

Atenção: Esta documentação apresenta apenas exemplos planejados. A API e o backend ainda não foram implementados. Nenhum desses endpoints funciona atualmente.
